Coloque aqui os .jar necessários:

  1) gson-2.11.0.jar      (obrigatório — JSON)
     curl -LO https://repo1.maven.org/maven2/com/google/code/gson/gson/2.11.0/gson-2.11.0.jar

  2) mysql-connector-j.jar (só se for usar o banco MySQL de verdade;
     dispensável se você usar o TarefaDAO em memória)

Depois de colar os jars, dê Refresh (F5) no projeto e um "Clean..." no Tomcat.
